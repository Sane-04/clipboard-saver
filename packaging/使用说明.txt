剪贴收藏 · Windows 便携版 1.0.13

一、开始使用
1. 将 ZIP 完整解压到有写入权限的文件夹，例如“文档”中的“剪贴收藏”。
2. 双击“剪贴收藏.exe”。不需要安装 Python、Anaconda 或 OCR 环境。
3. 保留 _internal 与 ocr-models 文件夹；只复制 EXE 会缺少运行库和模型。
4. 关闭历史窗口会收起到托盘并继续记录。右键托盘选择“退出剪贴收藏”才完全退出。
5. 更多或托盘菜单 →“登录 Windows 后自动启动”：勾选后下次登录收在托盘，
   取消勾选即可关闭。本包默认不开启，由使用者自己决定。
   启用后移动/重命名程序目录，需从新位置重新开启，以更新启动路径。
   同一用户只启动本工具的一份目录；给另一份目录开启会切换到新目录。
   如果在 Windows“启动应用”中另外禁用了本工具，需要在那里重新启用。

本包面向 Windows 10/11 的 64 位 x64 电脑。已在构建电脑的 Windows 上验证，
尚未在另一台实体电脑逐项验收。Windows 应保持系统更新，以提供程序使用的系统库。
本包没有代码签名；如系统显示发行者未验证，请核对下载来源和随包 SHA256。
1.0.13 精简了未使用的视频/可选依赖，保留本地 OCR、原图质量、Qt 软件绘制与 SSL。
ZIP 与解压文件夹是两份空间：日常只运行解压文件夹，ZIP 用作分享或离线备份。
已有历史的位置和大小独立于程序包；删除记录后 SQLite 可能保留可复用空页，
不能把删除条目数量直接当作磁盘已释放字节数。

二、常用功能
复制过的文字和静态图片会保存在本机；默认最多保留 1000 条普通记录。
Ctrl+Shift+V：调出历史。
Ctrl+Alt+X：框选截图，松开后可以继续调整选区、标注和编辑。
截图编辑工具栏上的蓝色“长截图”图标按钮：直接沿用当前选区，不需要重新框选。
原截图和已有标注会保留；取消采集回到原编辑器。
长图编辑器上的“继续长截图”沿用原区域，在已有长图后追加内容。
完成采集后仍可打码编辑，最终点击“完成”才复制保存一份成品。
历史/外部图片没有屏幕来源，长截图按钮禁用；先用 Ctrl+Alt+X 截图。
Ctrl+Alt+L：滚动长截图，更多菜单与托盘也有入口。
长截图默认手动滚动：框选内容区，松开调整后点击“开始长截图”，
自己缓慢向下滚动，每次保留部分已显示内容，稍停让程序自动拼接。
完成采集后进入图片编辑，最后点击编辑“完成”才复制保存。
工具条支持暂停/继续、撤回最近一段、完成和取消；自动滚动须主动选择并继续。
采集时默认显示“长截图实时预览”，直接看到已拼接内容，并自动跟随最新部分。
可拖动和调整预览窗口大小、向上查看前面的内容；点“跟随最新”回到底部。
蓝色虚线标出最近接入的位置，只用于提示，不写进最终图片。
关闭预览只隐藏窗口，采集继续；工具条的“实时预览”可重新打开。
预览优先避开截图区，若被拖入选区，截图前会短暂隐藏，采集后恢复。
本机支持时工具窗口由Windows直接排除截图，持续显示、不再每轮隐藏闪烁。
预览上方显示当前选区画面，下方显示已拼接长图；绿色框表示已接入的当前视口。
移动中或缺少重叠时上方仍显示实时画面并提示尚未接入，不把无效画面加入成品。
恢复到与已有内容重叠的位置后会自动继续；高度小的选区请每次少量滚动。
继续长截图保留原窗口和原区域，自动切回目标，支持连续多次追加。
最小选区50×40原像素；短选区可用较少重叠，但跳过整屏仍无法可靠补回漏掉的画面。
采集范围有明显边框，蓝色表示采集中，橙色表示暂停；边框不会挡住鼠标滚动。
范围固定在最初的选区，预览显示已经接入长图的进度；提示边框不进入成品。
完成采集进入编辑后，在画布上 Ctrl+向上滚轮放大，Ctrl+向下滚轮缩小。
以鼠标位置为中心，支持5%到800%；普通滚轮仍查看上下内容。
工具栏更多 → 显示比例 → 适应窗口，可以恢复全图适应显示；缩放不改变导出像素。
拼接不确定时暂停，请退回一点恢复重叠；固定栏、动画、重复图案要避开选区。
上限长边30000像素、总像素3000万，到上限暂停，可完成已有内容。
长图本地OCR分段提取；提取不自动翻译，也不上传图像。
Ctrl+Enter：完成图片，复制并保存成品。
Ctrl+Z / Ctrl+Y：撤销 / 重做编辑。
更多 → 快捷键设置：修改上述快捷键，遇到冲突可以改成其他组合。
日期按钮可以选全部日期、指定日期或范围；特殊标记可添加标签并搜索。

三、文本提取与翻译
打开图片 → 文本提取与翻译：自动用 RapidOCR 在本机提取文字，
不需要 Key，不上传图片。包内已有模型，不需要第一次联网下载。
提取完成后可以校对、复制原文，也可以主动点击“翻译”。
点击文字块列表上方“全部文字”，打开可移动、调整大小的全文窗口，默认全选所有原文。
左侧独立勾选要复制的文字，支持全选、全不选和反选；右侧只汇总勾选内容。
不需要的行取消勾选即可，不改变图片翻译范围。右侧支持跨行拖选、Ctrl+A及Ctrl+C。
点击“复制全部原文”一次复制全部；取消部分勾选后按钮变成“复制勾选原文”。
切换“译文”页可同样选择并复制已有译文。校对及翻译结果同步刷新；
重新提取会重新全选新结果，关闭编辑器时全文窗口一起关闭。
需要翻译时，打开“更多 → 文字识别与 API 设置”，填写自己的
Base URL、API Key 和模型，选择目标语言。兼容 Chat Completions 接口。
新用户的默认接口地址是 https://s2api.top/v1，模型是 gpt-5.6-luna，
这些字段可以修改，包内没有任何已配置的真实密钥或预付额度。
翻译将文本块发送给你选择的服务；如选择 API OCR，图片也会发送到所选服务。
翻译结果替换图片中的文字，完成前可以调整文字框并校对效果。
照片、纹理、渐变背景以及很小或旋转的文字仍需人工检查。

四、数据与保存位置
首次启动从空白历史开始，在 EXE 所在文件夹创建 data。
更多 → 数据保存位置：分别修改历史、接口与快捷键、OCR 模型、备份、
日志和成品导出的文件夹。点击“迁移并保存”后复制既有数据，原文件保留。
更多或托盘 → 删除指定日期以前的数据：选择截止日期，预览数量后点击删除并确认。
仅清理严格早于截止日的数据，不包含当天，默认保留固定和特殊标记记录。
可勾选同时删除固定和特殊标记；较新日期也复制过的相同内容仍保留，只删旧归档。
此操作不受当前查询筛选影响，删除无法撤销；设置、模型、备份及另存PNG不受影响。
本地 OCR 模型默认位于本包的 ocr-models 文件夹。
API Key 用当前 Windows 用户 DPAPI 加密；换电脑/用户后需要重新填写。
data-locations.json 保存自选的绝对路径。配置位置后移动程序或改变盘符前，
请先检查这些路径；对方电脑无法直接使用你的路径配置。
备份历史前先从托盘退出，再备份自己的历史库和配置。

五、分享与更新
将最初收到的干净 ZIP 发给别人即可。包内没有原作者的历史、截图、标签、
备份、日志、密钥或个人路径配置。
运行过的文件夹可能含有你自己的私人数据，不要将它重新压缩发给别人。
升级建议将新版解压到新文件夹，再按实际需要选择/迁移你自己的数据。
不要覆盖正在运行的 _internal；始终先从托盘退出。

遇到启动错误：检查是否完整解压、是否放在可写目录、系统是否已更新；
程序启动错误详情会尽可能保存到 data/startup-error-*.txt。
如需诊断，在程序目录打开 PowerShell，执行：
& '.\剪贴收藏.exe' --self-check '.\自检结果.json'
这只处理临时合成图片、模拟剪贴板和本机模拟接口，不读取真实历史或剪贴板，
会生成 JSON 报告和合成验证图片；自检通过后正常退出。

六、空译文与漏译处理（1.0.7）
文字较多时分批翻译，每批最多32块或约6000字符。
空译文/漏译项只自动补译一次，补译每批最多4块；可随时取消。
成功译文正常替换到图片预览；仍未完成的块显示“⚠ 未完成”，保留原画面。
点击“重试未完成”只重试这些块，也可以选中块手动填写译文。
修改目标语言、所选范围或原文后，点击“翻译所选”重新翻译所选内容。
纯数字/标点无需换语言时保留原文；未知/重复编号仍拒绝，不能按顺序错配。
仍须点击“完成”才复制保存成品。接口持续无译文时可在设置中更换模型。

七、置顶、独立图片窗口、模型列表与内容更新（1.0.8）
主窗口、独立图片和普通编辑器原有图钉在1.0.11统一进入选窗，见第八节。
全屏截图仍按原规则置顶。
双击图片记录或右侧图片预览，打开独立只读图片窗口；可同时打开多张。
图片窗口有图钉选窗入口，并提供“适应窗口”和“100%”。
图片预览中Ctrl+向上滚轮放大、Ctrl+向下滚轮缩小，普通滚轮继续滚动。
鼠标位于图片上时按原像素位置缩放；边界处按滚动范围限制，空白处按视口中心缩放。
状态栏显示比例；手动倍率在调整窗口大小后保留，可点适应窗口或100%复位。
收起/关闭剪贴板主窗口不关闭图片窗口；从托盘真正退出程序会关闭全部窗口。
文字记录双击仍复制，图片要复制可用Enter或“复制并收起”。

更多 → 文字识别与 API 设置：有密钥时打开会读取当前接口模型列表，
可点“刷新模型”更新、取消读取，或在可输入下拉框中输入模型名/关键词。
读取失败仍可手动填写；列表不会自动替换当前模型，保存才写入配置。
接口返回模型名称不代表都支持图片识别，图像能力由服务商决定。

文字记录右侧“编辑内容”或右键同名项：修改后点“保存修改”更新原记录。
图片点“编辑图片”，工具栏选择“更新原记录”，再点击“完成”。
默认“另存为新记录”保留此前复制与保存成品的操作；更新原记录不改剪贴板。
固定、特殊标记、标签和日期归档保留，同一记录在各日期中同步更新。
重复内容冲突、原记录删除/被更新、写入失败会保留编辑内容，不静默覆盖其他记录。
独立图片查看器显示打开时的图片快照，修改历史图片后可重新打开查看更新结果。

八、图钉选窗与点击取消（1.0.11）
点击原有“置顶”图钉，鼠标变成十字加图钉，目标窗口显示蓝色边框。
左键选择窗口并置顶，选择点击不会传给目标内容；Esc或右键取消。
目标顶部中央显示蓝色图钉，点击它取消置顶。可重复选择不同窗口。
图钉跟随目标移动/缩放，最小化、隐藏或被其他置顶窗口遮挡时隐藏，恢复后重现。
剪贴收藏自己的普通窗口也可选择。更多/托盘中的旧窗口列表入口已经移除。
收起剪贴板窗口不影响外部置顶；真正退出时恢复本轮由工具新加的置顶。
目标选择前已置顶则退出时保留原状态，主动点蓝色图钉仍会取消置顶。
目标关闭不追踪新窗口；切换应用/显示器变化退出选择，截图中暂不选窗。
权限/窗口身份/未响应导致失败时提示，不自动提权或持续强制层级。
强行终止进程无法执行退出还原。实体混合DPI多屏及特殊软件需实际复核。
窗口标题只在本机内存中使用，不进入剪贴历史、配置或日志。

第三方许可证和组件清单见“第三方许可”文件夹。
